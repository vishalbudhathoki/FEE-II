# Product Cart

An interactive Product Cart application built with React and Vite.

## Features

- **Product Catalog**: Display of gadgets and electronics with live pricing and image previews.
- **Dynamic Counter**: Real-time increment and decrement controls for each product.
- **Cart Summary & Subtotal**: Live calculation of total items and total price.
- **Interactive Cart Table**: View, adjust quantities, and remove items directly from the cart table.
- **Checkout Flow**: Quick checkout action with cart reset.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
